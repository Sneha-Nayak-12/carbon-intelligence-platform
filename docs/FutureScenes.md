# Future Scenes Implementation Roadmap

This document outlines the proposed roadmap for expanding the interactive documentary experience in the future.

---

## 1. Scene Additions & Extensions

### Scene A: Gaseous Decay (Chapter 2 Initial State)
- **Objective**: Establish the source of captured carbon visually.
- **Narrative Purpose**: Link decaying agricultural waste with atmospheric carbon gas.
- **Required Assets**: SVG decay path vectors, small plant residue particles.
- **Expected Animations**: Free-falling molecules descending from the space scene down to the pyrolysis chamber.
- **Technical Difficulty**: Low-Medium (can reuse the existing `CO2Molecule` trail physics).

### Scene B: Verification Stamp Seal Expansion
- **Objective**: Draw a more elaborate physical auditor verification sequence.
- **Narrative Purpose**: Build scientific confidence.
- **Required Assets**: Sound chimes, high-resolution SVG seal.
- **Expected Animations**: The stamp rotates and snaps down with a particle blast upon scroll intersection.
- **Technical Difficulty**: Low.

### Scene C: Live Registry Node Sync (Detailed Ledger)
- **Objective**: Elevate the Public Registry visual representation.
- **Narrative Purpose**: Prove absolute cryptographic auditing.
- **Required Assets**: Cryptographic terminal log sounds.
- **Expected Animations**: Glowing data rows sliding in from the sides like scanning laser beams.
- **Technical Difficulty**: Medium.
